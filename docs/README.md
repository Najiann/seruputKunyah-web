# Seruput & Kunyah — Documentation Pack

Dokumentasi awal untuk ditinjau dan digabungkan ke repository project.

## Isi
- `docs/PRD.md` — kebutuhan produk dan aturan bisnis.
- `docs/ARCHITECTURE.md` — arsitektur target dan batas keamanan.
- `docs/DATABASE.md` — model data konseptual.
- `docs/ROADMAP.md` — tahapan dan checklist pengembangan.
- `docs/TEST_PLAN.md` — skenario pengujian.

## Cara menggunakan
1. Unduh dan ekstrak ZIP ini.
2. Periksa folder `docs/` pada project lokal.
3. Jika file dengan nama sama sudah ada, bandingkan dan gabungkan; jangan langsung menimpa dokumentasi yang sudah ada.
4. Review asumsi stok produk jadi di PRD dan DATABASE.
5. Commit dokumentasi melalui branch fitur, bukan langsung ke `main`.

Dokumen ini masih berupa draft. Ini bukan migrasi database atau implementasi aplikasi. Audit source code dan konfirmasi kebutuhan bisnis tetap diperlukan sebelum schema dan kode final dibuat.
